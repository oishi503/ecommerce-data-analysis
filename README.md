## E-commerce Data Analysis

This project performs exploratory data analysis (EDA) on an e-commerce dataset using Python.

The objective of the analysis is to understand customer behaviour, sales patterns, and trends through data cleaning, transformation, and visualisation.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis Performed
- Data cleaning and preprocessing
- Handling missing values
- Exploratory analysis of sales data
- Visualisation of trends and patterns

## Files
- `Ecommerce_data analysis.ipynb`: Main notebook containing the full analysis

## Purpose
This project was created to practice data analysis skills and gain hands-on experience working with real-world datasets using Python.
